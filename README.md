# SolidLab — Mechanics of Solids

SolidLab is a self-contained, browser-based learning project that turns core mechanics-of-solids equations into interactive visual models. It is designed for students meeting the subject for the first time.

**Author:** Lohith Midathana · **Institution:** IIT Hyderabad · **Course:** Mechanics of Solids · **Version:** 1.0

## Open the app

Visit the live site: **https://lohith777-me.github.io/solidlab-mechanics-of-solids/**

To run it locally, open [`index.html`](index.html) in a current desktop or mobile browser. No installation, build step, account, or network access is required.

## Included modules

- Axial loading
- Shaft torsion
- Beam bending
- Shear-force and bending-moment diagrams
- Mohr's circle
- Stress–strain curve
- Universal testing machine / tensile-test simulator

The app includes editable inputs, live model views and calculations, beginner guidance, unit and theme toggles, worked-solution printing, CSV/PDF export, and shareable input links.

## Educational scope and limitations

The calculations are analytical teaching models, not finite-element analyses or certified test software. Material curves and strengths are representative teaching values. Visual deformation and fracture animations are illustrative and do not predict real component failure. The UTM visualization is not calibrated and does not implement a standards-compliant ASTM test.

This project is not a design, safety, inspection, testing, or certification tool. Independently verify assumptions, data, and calculations before applying them to real systems.
